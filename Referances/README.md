# Reference library manifest

The local working directory contains 30 source papers used for literature
review and citation verification. The article PDFs are intentionally excluded
from GitHub because they may be copyrighted and are not required to reproduce
the project.

Use the following tracked files instead:

- `../medvision_25_references_synthesis.md` — structured literature synthesis
- `../My writing/related_work_references.bib` — related-work BibTeX records
- `../My writing/methodology_references.bib` — methods and reporting references

Obtain articles from their publisher pages, DOI records, PubMed, or authorised
institutional access.
