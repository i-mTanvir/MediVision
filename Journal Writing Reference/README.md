# Informatics and Health writing reference

This directory retains the reusable journal-writing guidance derived from five
recent *Informatics and Health* articles:

- `informatics-health-journal-writing/SKILL.md`
- `informatics-health-journal-writing/references/format-patterns-from-five-papers.md`

The downloaded publisher PDFs are intentionally excluded from GitHub. Consult
the journal website or publisher for the original articles.
